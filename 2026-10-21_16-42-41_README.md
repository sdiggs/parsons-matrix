# The Parsons Matrix

**Live site: [https://sdiggs.github.io/parsons-matrix/](https://sdiggs.github.io/parsons-matrix/)**

The Parsons Matrix maps who works where in research data stewardship. It places each organization on three axes: the disciplines it serves, the part of the data chain it works on, and the people who use what it produces. The original figure was a static 3D grid that came out of network mapping work; this site plots real organizations inside it so you can see the shape each one occupies and where the space is empty.

## What's on the page

- A rotatable 3D cube with a show/hide button for each organization. Isolating one organization at a time is the clearest way to read its shape.
- The three axes, with the values added after placing real organizations marked.
- A placement table with a short description of each organization.
- Findings so far, and open questions for reviewers.

## The axes

- **Disciplines:** EES (Earth and environmental science), Life science, Physical science, Social science, Medicine.
- **Components:** Source, Repository, Standards, Integrators, Interfaces, and Coordination (added).
- **Users:** Researchers, CBOs, Policy makers, Decision makers, Investors, Risk analysts, Funders (added), and Journalists (added).

## Organizations plotted

NYCE's Data Stewardship Initiative (DSI), KCF's Planetary Vital Signs Initiative (PVSI), the Data Foundation's Center for Climate and Environmental Data (CCED), the Coalition for Resilient Research Data Infrastructure (CRRDI), the AGU Data Resilience Project, the Data Rescue Project, CODAN, NIH's Generalist Repository Ecosystem Initiative (GREI), the Environmental Data and Governance Initiative (EDGI), Public Environmental Data Partners (PEDP), and the Open Environmental Data Project (OEDP).

## Status

The placements are a first pass by Steve Diggs, drawn from each organization's public materials and his working knowledge of the field. They're meant to be argued with. Solid points mark an organization's home disciplines; faint points mark reach beyond its mandate.

## How it's built

The site is a single static `index.html` with no build step. It loads Plotly.js 2.27.0 from cdnjs and its typefaces from Google Fonts. All placements live in one JavaScript array (`O`) near the bottom of the file, so adding an organization means adding one entry with its disciplines, components, and users. The page follows the viewer's light or dark setting.

GitHub Pages serves the site from `index.html` at the root of the `parsons-matrix` repository.
